
# Email Risk Analyzer

## Project Description
A Python-based cybersecurity tool that analyzes email content and identifies potentially suspicious messages using keyword detection and URL pattern analysis.

## Features
- Detects urgent and threatening language.
- Identifies potentially suspicious links.
- Detects requests for passwords, OTPs and PINs.
- Identifies suspicious financial requests.
- Calculates an email risk score.
- Classifies emails into Low, Medium and High Risk.
- Provides security recommendations.

## Technologies Used
- Python 3
- Regular Expressions (re module)
- Python IDLE

## How to Run
1. Download the Python file.
2. Open it in Python IDLE.
3. Press F5.
4. Paste sample email content.
5. View the risk level and security warnings.

## Objective
To understand phishing detection, email security, suspicious patterns and basic cybersecurity analysis.

## Disclaimer
This is an educational, rule-based analyzer. It does not guarantee email safety or replace professional email security tools.
